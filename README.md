# javascript-calculator-precourse

## 1주차 - 문자열 덧셈 계산기

### 구현할 기능 목록

- '덧셈할 문자열을 입력해 주세요.' 라는 문구가 뜨면 다음 줄에 문자열을 입력할 수 있는 부분이 존재한다.
  <br/>
  <br/>
- 이때, 사용자는 기본 구분자인 쉼표(,)와 콜론(:) 이외에 커스텀 구분자를 지정할 수 있다. 문자열 앞 부분의 "//"와 "\n" 사이에 위치하는 문자(문자들)만을 커스텀 구분자로 사용한다.
  <br/>
  <br/>
- 이때, 문자열 앞 부분이 아닌 다른 곳에 "//~~\n"를 입력하면 "[ERROR]: 커스텀 구분자 지정은 문자열 맨 앞 부분에서 해주세요."라는 메시지와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- "//"와 "\n" 사이에 오는 모든 값들은 각각 커스텀 구분자로 취급한다. 예를 들어, //&\*!\n는 &, \*, ! 각각이 커스텀 구분자이다.
  <br/>
  <br/>
- 이때, "//"와 "\n" 사이에 기호나 특수문자가 아닌 글자가 들어오면 "[ERROR]: 글자는 커스텀 구분자로 지정할 수 없습니다."라는 메시지와 함께 애플리케이션이 종료된다.
  <br/>
  <br/>
- 사용자가 커스텀 구분자(들)를 지정하면, 구분자 세트는 원래 기본 구분자였던 쉼표(,)와 콜론(:) 그리고 커스텀 구분자(들)를 모두 포함한다.
  <br/>
  <br/>
- 기본적으로, 입력된 문자열에서 구분자 세트에 지정된 구분자와 숫자 외의 값들은 모두 무시된다.
  <br/>
  <br/>
- 사용자가 문자열을 입력하면, 해당 문자열에서 커스텀 구분자가 있는지 가장 먼저 확인 후 구분자 세트를 확립한다.
  <br/>
  <br/>
- 구분자로 분리된 부분들을 반환한다.
  <br/>
  <br/>
- 반환된 부분들 중, 숫자로 이루어진 것이 아닌 다른 것은 무시하고 숫자만을 더한다.
  <br/>
  <br/>
- 더한 결과는 '결과: '라는 글자 뒤에 추가해 출력한다.
