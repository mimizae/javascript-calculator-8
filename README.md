# javascript-calculator-precourse

## 1주차 - 문자열 덧셈 계산기

### 구현할 기능 목록

- '덧셈할 문자열을 입력해 주세요.' 라는 문구가 뜨면 다음 줄에 문자열을 입력할 수 있는 부분이 존재한다.
  <br/>
- 이때, 사용자는 기본 구분자인 쉼표와 콜론 이외에 커스텀 구분자를 지정할 수 있다. 문자열 앞 부분의 "//"와 "\n" 사이에 위치하는 문자만을 커스텀 구분자로 사용한다.
  <br/>
- 사용자가 문자열을 입력하면, 해당 문자열에서 커스텀 구분자를 가장 먼저 처리한다.
  <br/>
- 커스텀 구분자가 있다면 커스텀 구분자를 포함, 없다면 기본 구분자인 쉼표(,) 혹은 콜론(:)만을 가지고 구분자들을 기준으로 숫자를 분리해 반환한다.
  <br/>
- 반환된 숫자들을 모두 더한다.
  <br/>
- 더한 결과는 '결과: '라는 글자 뒤에 추가해 출력한다.
  <br/>
- 사용자가 잘못된 값을 입력하는 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션을 종료 시킨다.
